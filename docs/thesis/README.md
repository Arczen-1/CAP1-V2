# Thesis Source Folder

Place the approved thesis paper and relevant capstone documents in this folder.

Recommended filename:

thesis-original.pdf

Other supported source files may include:

- approved-requirements.docx
- architecture.md
- scope-and-limitations.md
- revisions.md
- panel-comments.md

The AI workflow treats these documents as the source of truth.

Do not place passwords, API keys, production credentials, student private data,
or private company credentials in this folder.
